Telecom Customer Churn & Retention Dashboard

Project Overview

A customer churn and retention analysis project focused on understanding customer behavior, identifying churn patterns, and generating actionable business insights to support customer retention strategies.

Tools & Technologies

* Microsoft Power BI
* DAX
* Power Query

Project Workflow

1. Data Cleaning: Cleaned and prepared telecom customer data for analysis.
2. Data Modeling: Organized the data model to support accurate analysis and reporting.
3. Dashboard Development: Built interactive Power BI dashboards using DAX measures to analyze customer churn and retention performance.

Key Analysis Areas

* Customer Churn Rate
* Customer Retention Patterns
* Contract Type Analysis
* Internet Service Analysis
* Customer Behavior and Churn Trends

Dashboard

The interactive dashboard provides insights into customer churn patterns and key factors associated with customer loss, helping support data-driven retention decisions.
